## Legend

- **Input (Cache Hit):** Approximate cost per **1M input tokens** when prompt caching applies (if supported by provider)

- **Input (Cache Miss):** Cost per **1M input tokens** for new/un-cached context

- **Output:** Cost per **1M output tokens generated by the model**

- **Source:** Official pricing page for verification

- **Notes:** Extra details like discounts, routing, or positioning
